How to use this calculator

  1. Choose a start date.
  2. Choose an end date.
  3. Calculate to see the absolute number of days and which date comes first.
Days between dates = absolute difference between the two calendar dates. The count excludes the start date; add one if you need an inclusive count.

Frequently asked questions

Does the result include both dates?

No. It counts elapsed days. For an inclusive count, add one day.

Can the end date be earlier?

Yes. The calculator shows the difference and notes which date comes first.

Does time of day matter?

No. This tool compares calendar dates, not hours.
