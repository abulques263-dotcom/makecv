# SmartEarn — Marks & Percentage Calculator

A free, responsive calculator for students. Built with plain HTML, CSS, and JavaScript—no framework, backend, database, or API key.

## Files
- `index.html` — accessible page structure and content
- `styles.css` — responsive styling and print rules
- `app.js` — validation, aggregate percentage, target estimate, reset, and print
- `README.md` — setup and publishing notes

## Use locally
Open `index.html` in a modern browser. No installation or build step is needed.

## Publish with GitHub Pages
1. Open this repository's **Settings → Pages**.
2. Under **Build and deployment**, select **Deploy from a branch**.
3. Choose branch `main` and folder `/ (root)`, then save.
4. Wait for GitHub Pages to finish publishing; the URL will appear in Settings → Pages.

## Privacy and limitations
Marks are processed in the browser; this site does not send entered scores to a server. Results use total marks scored divided by total maximum marks. Schools and universities can use different rounding, grading, or CGPA rules. The target estimate assumes the same total maximum marks.

This is an early MVP. It has no monetization or analytics, and income is not guaranteed.
